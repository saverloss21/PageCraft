# PageCraft

人人都可以直接做出自己网页的可视化编辑器。

## 当前 MVP

- `src/main.jsx`：编辑器交互与页面 JSON 数据模型
- `src/styles.css`：编辑器工作台与预览页面的基础视觉样式
- `package.json`：React + Vite + Lucide 图标

当前可以直接完成一张简单网页：

- 添加首屏、特性区、图片、文字和按钮区块
- 在右侧面板修改标题、描述和按钮文字
- 拖拽区块调整顺序，或删除不需要的区块
- 进入预览模式查看页面效果
- 自动保存到浏览器本地草稿，并导出为 JSON

## 本地运行

```bash
npm install
npm run dev
```
