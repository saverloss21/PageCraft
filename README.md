# PageCraft

人人都可以直接做出自己网页的可视化编辑器。

## 当前 MVP

- `src/main.jsx`：编辑器状态、交互、兼容处理与静态导出逻辑
- `src/app-config.js`：将 JSON 转换为编辑器可直接使用的配置与默认值
- `src/data/app-data.json`：组件目录、默认内容、视觉配方、主题、模板和编辑器选项
- `src/data/i18n.json`：中英文界面、组件目录、模板元信息与默认内容翻译
- `src/i18n.js`：语言持久化、界面切换和新建内容本地化逻辑
- `src/styles.css`：编辑器工作台与预览页面的基础视觉样式
- `scripts/validate-app-data.mjs`：构建前检查 JSON 引用、重复项和必填字段
- `package.json`：React + Vite + Lucide 图标，使用 fflate 在浏览器内生成网站 ZIP

- 进入预览模式查看页面效果

## 本地运行

```bash
npm install
npm run dev
```

## 修改内置数据

内置内容集中在 `src/data/app-data.json`，修改时无需进入 React 交互代码：

- `components`：左侧组件目录、名称、说明和图标键名
- `blockDefaults`：新增区块的默认文案、列表和初始表现
- `styleDefaults`：不同区块的默认背景、留白和高度
- `itemEditors`：列表型区块的字段定义与编辑说明
- `visualRecipes`：一键视觉配方
- `contentRecipes`：针对不同区块的一键文案与列表配方
- `themes`：整页主题目录
- `templates`：完整页面模板
- `editorOptions`：属性面板中的常用选项

修改后可单独运行数据检查：

```bash
npm run validate:data
```

`npm run dev` 和 `npm run build` 都会自动先检查数据。区块类型、主题或图标引用错误时，命令会直接指出对应 JSON 路径。

修改现有区块的名称、文案、默认列表、配方和模板时只需要编辑 JSON。若要新增一种全新的区块类型，仍需在 `main.jsx` 和 `styles.css` 中补充编辑预览、静态导出及样式实现，再将类型登记到 JSON。
